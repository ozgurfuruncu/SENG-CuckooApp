# Historical Sprint 1 records

These files preserve the project's earlier proposal, stack evaluation, starter
contract/backlog and agent inspection reports. They describe their original dates
and must not be treated as current deployment, permission or release state.
The current guide is [the root README](../../README.md); the current contract is
[api/openapi.yaml](../../api/openapi.yaml).

- `initial-starter`: superseded OpenAPI 3.0/backlog and the exact original README.
- `submissions`: exact supplied Word source; its hash is recorded in the current
  submission index. The evidence-filled working document is in docs/submissions.
- `preselection`: architecture options and unmeasured evaluation before Stack A approval.
- `handoffs`, `planning`, `proposals`: historical prompts/plans and reconciliation notes.
- `audits`, `release-preparation`: dated command/CI evidence, old permission payloads
  and attestation snapshots. These are historical evidence, not active tooling.
